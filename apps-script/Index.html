Google Apps Script — Project Inventory

Audits every Apps Script project in your Drive — files, OAuth scopes, recent executions — running entirely as you. Nothing is stored server-side; results live in this page until you download them.

Container-bound projects (Sheets / Docs / Slides / Forms)

Google hides bound scripts from Drive listing, so no scan can find them automatically. Paste their script IDs below — one per line, from each project's editor URL (script.google.com/home/projects/<ID>/edit) — and they'll be included in every scan. They're remembered in this browser only (localStorage); nothing is stored server-side. Tip: Download script IDs after a scan gives you an editable file with every known project already listed — the same file the Python CLI accepts via --script-ids-file.
